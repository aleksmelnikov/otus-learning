# 📚 Изучение технологий и курсов OTUS

Добро пожаловать в репозиторий, созданный для консолидации знаний, выполнения домашних заданий и практических работ в рамках обучения на платформах **OTUS**.

- **Языки программирования:** C++
- **Инструменты и DevOps:** Git / Github

## 📂 Структура репозитория

Каждый курс или крупный модуль находится в отдельной директории. Внутри папок с домашними заданиями могут быть свои локальные инструкции по запуску.

```text
.
├── 📁 course-name-1/         # Название первого курса (например, cpp-basic)
│   ├── 📁 homework-01/       # Выполненное домашнее задание №1
│   └── 📁 homework-02/       # Выполненное домашнее задание №2
├── 📁 course-name-2/         # Название второго курса
└── README.md                 # Главный файл описания (этот файл)
```

## 🚀 Как запустить проекты локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd otus-learning
   ```

2. **Перейдите в папку нужного курса:**
   ```bash
   cd course-name-1/homework-01
   ```

3. **Следуйте инструкциям:**
   Внутри каждой папки с ДЗ создается индивидуальный `README.md` с шагами по настройке окружения и командами запуска.
